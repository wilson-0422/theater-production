# 剧目排演管理系统

## 项目简介

剧目排演管理系统是一个面向剧院和演出团体的全流程管理平台，涵盖剧本存档、演员排班、道具服装领用、剧场档期和巡演行程台账等核心功能模块。

## 技术栈

- **后端框架**: Go 1.22 + Gin Web Framework
- **数据库**: SQLite（通过 GORM ORM）
- **前端渲染**: Go html/template 模板引擎
- **认证方案**: Gin Sessions（基于 Cookie 的会话管理）
- **密码加密**: bcrypt（golang.org/x/crypto）

## 功能模块

### 1. 剧本存档
- 剧本信息的增删改查
- 剧本状态管理：草稿、排练中、演出中、已归档
- 支持话剧、昆曲、京剧、音乐剧、舞剧等多种类型
- 剧情简介、作者、时长等详细信息管理

### 2. 演员排班
- 演员基本信息管理（姓名、性别、电话、特长）
- 角色类型分类：主演、配角、群演
- 排班日期安排与状态追踪
- 演员状态管理：空闲、忙碌、请假

### 3. 道具服装领用
- 道具和服装分类管理
- 库存数量与可用数量追踪
- 领用申请与审批流程
- 归还日期记录与状态管理

### 4. 剧场档期
- 剧场信息维护（名称、地址、容量、设施）
- 演出排期管理
- 档期状态追踪：已预约、已确认、已取消
- 精确到分钟的时段安排

### 5. 巡演行程台账
- 巡演计划制定与管理
- 城市和场馆安排
- 行程状态追踪：计划中、已确认、进行中、已完成、已取消
- 巡演备注与详细信息

### 6. 仪表盘
- 关键数据统计概览
- 最近剧本列表
- 进行中和计划中的巡演展示
- 一目了然的系统状态

## 快速开始

### 本地运行

```bash
cd repo
go mod tidy
go run ./src/
```

访问 http://localhost:8080 即可使用系统。

### Docker 运行

```bash
cd theater-production
docker build -t theater-production .
docker run -p 8080:8080 theater-production
```

## 开发说明

### MVC 架构

本项目采用经典的 MVC 架构模式：

- **Models**: 定义数据结构和 GORM 模型
- **Services**: 封装业务逻辑和数据库操作
- **Controllers**: 处理 HTTP 请求，调用 Services，渲染模板
- **Templates**: Go html/template 模板，中文界面

### 认证机制

- 基于 Gin Sessions 的 Cookie 会话管理
- 支持管理员、导演、工作人员三种角色
- AuthRequired 中间件保护需要登录的路由
- AdminRequired 中间件保护管理员专属路由

### 数据库

- 使用 SQLite 作为数据库，无需额外配置
- GORM 自动迁移表结构
- 数据库文件：`theater.db`
